Hinweis

Audiozugriff funktioniert in Chrome in der Regel nur über HTTPS oder localhost. Beim direkten Öffnen einer lokalen HTML-Datei kann die Berechtigung fehlen. Für den Test die Datei auf GitHub Pages veröffentlichen. Diese Anwendung speichert Audio nur lokal im Browser, lädt nichts hoch und benötigt keine Internetverbindung nach dem Laden.
